# API release readiness

## Contract

Confirm the intended version, operations, types, constraints, compatibility analysis, and security requirements. Resolve schema/implementation disagreements.

## Documentation

Update references, tutorials, authentication, errors, examples, downloads, release notes, and migration guidance. Regenerate derived files.

## Testing

Run syntax and structural checks, schema/example validation, operation execution, authorization tests, boundary tests, and browser review. Record blockers honestly.

## Approval and timing

Obtain accountable engineering, product, and security review where relevant. Align publication with the actual rollout and supported environments.

## After release

Check published links and first-success workflow. Assign feedback and defect ownership. Preserve a rollback path and the prior supported documentation version.
